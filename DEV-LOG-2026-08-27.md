## 5. Node.js Backend — Time Estimate

### Tech Stack Recommendation
- **Runtime**: Node.js 18+ LTS
- **Framework**: Express.js or Fastify
- **ORM**: Prisma or TypeORM
- **Database**: PostgreSQL (recommended) or MySQL
- **Auth**: JWT (jsonwebtoken + bcrypt)
- **Validation**: Joi or Zod
- **File Upload**: multer + xlsx
- **Logging**: Winston
- **Testing**: Jest + Supertest

### Phase Breakdown

| Phase | Work | Time |
|-------|------|------|
| Project Setup | Node.js + Express, JWT auth, DB connection, project structure | 2-3 days |
| Auth Module | Login, JWT issue/verify, bcrypt, refresh tokens, role middleware | 2-3 days |
| Core CRUD (15 entities) | Models, controllers, routes for all 15 entities | 5-7 days |
| Custom Endpoints | ~8 custom queries (GetProductByRFIDorBarcode, etc.) | 2-3 days |
| Multi-tenancy | refOrgId scoping on all queries, org management | 2-3 days |
| File Upload | Excel import endpoints (products, RFID, devices, reference lists) | 2-3 days |
| Validation + Errors | Request validation, consistent error responses, logging | 2-3 days |
| Dashboard Aggregations | Stats queries (products, sales, transfers, charts) | 1-2 days |
| Web Dashboard | Login, all admin CRUD pages, reports, dashboard | 10-15 days |
| Testing | Unit + integration tests | 3-5 days |
| Deployment | PM2/Docker, SSL, CI/CD | 1-2 days |

### Total Estimates

| Scope | Time (1 dev) | Time (2 devs) |
|-------|-------------|---------------|
| Backend API only | 3-4 weeks | 2-3 weeks |
| Backend + Web Dashboard | 7-10 weeks | 4-6 weeks |

> Using Prisma + same REST contract as existing API cuts 30-40% time since the mobile frontend already knows the contract.
