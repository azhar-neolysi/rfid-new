## Urovo DT50 Compatibility Research

### Key Findings

| | Current (Zebra RFD4031) | Urovo DT50(D) |
|---|---|---|
| RFID Module | External Bluetooth/USB sled | **Built-in** UHF |
| SDK | Zebra API3 (`rfidapi3lib`) | **Urovo SDK** (`URFIDLibrary` AAR + `platform_sdk` JAR) |
| Connection | BT discovery → pair → connect | AIDL service binding (always available) |
| Tag speed | ~50 tags/sec | 50-1000+ tags/sec |

### Current State of Native Plugin
**CRITICAL: The native Java plugin does NOT exist in the current codebase.**

- `MainActivity.java` is bare: just `extends BridgeActivity {}`
- No `RFIDScannerPlugin.java`, `NativeRFIDReader.java`, `BarcodeScannerPlugin.java`, or `NativeBarcodeReader.java` exist on the `main` branch
- These files exist only in the backup branch (old code)
- No Zebra SDK or Urovo SDK in any `build.gradle`
- Missing Bluetooth/USB/Location permissions in `AndroidManifest.xml`
- Only `INTERNET` permission is declared

### TypeScript Layer (Fully Defined, No Changes Needed)
- `src/app/services/rfid-scanner.models.ts` — Plugin interface (connect, disconnect, startInventory, stopInventory, writeEpc, readMemory, etc.)
- `src/app/services/hardware-rfid.service.ts` — Angular wrapper (auto-connect, tagRead$ observable, connection state)
- Registered as `registerPlugin<RFIDScannerPlugin>('RFIDScanner')`
- Plugin contract already supports `usb` and `bt` transport modes
